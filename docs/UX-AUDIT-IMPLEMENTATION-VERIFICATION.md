## Implementation/source decisions

Championship reads published driver and constructor standings at the same season-owned round/publication, not a derived race sum. Selected analytical entities/circuit/session/from-to rounds narrow results, not latest season championship. Published rank/points/wins/numbers remain source-backed. The new compact summary separately checks actual driverCoverage/constructorCoverage, season/publication and each row's standingSnapshotId; unavailable sets containing unexpected rows cannot populate it. Decimal source points are retained. The source contract is [API analytics metrics](../../api/docs/ANALYTICS-METRICS.md); OpenAPI additions/checksum require no migration.

Retirement semantics are shared in the API: known finished/retired starts form the denominator, explicit retirement the numerator, including classified retirement. DNS/withdrawn are non-starts; positive published laps can establish a start without a known finishing outcome. Classification is true/false/unknown from the explicit boolean, never inferred from rank. Observed48.7% describes normalized published statuses, not an independently verified official DNF total. Qualifying legacy comparison races denotes entries, explicitly labelled through qualifyingEntries/startDefinition; per-race points and retirement are null there. Genuine0 points/starts/absence distinctions are preserved; all-null series never claim populated drivers.

Evidence links carry the actual recordId plus an actual clicked field, or record-only for generic qualifying/laps/pit-stop links. Dataset assertion /items/i/id selectedValue resolves its own index (independent fixtures4/7), not page index0. Missing/ambiguous record and unknown field give explicit not-found, no fallback. All technical assertions remain reachable; back preserves actual season/session/view/snapshot/cursor. Mobile meaning explains source-only/partial/no independent guarantee concisely.

Shared time display formats anchored source instants via Intl and an explicit viewer zone, with simultaneous UTC secondary in Local mode. Storage-write failure preserves the in-memory choice; cross-consumer updates/reset/unmount are tested. Countdown instant/arithmetic is unchanged. Strict date-only UTC calendar formatting prevents rollover and invented midnight; venue zone is supplied circuitTimeZone or unavailable. Calendar's duplicate zone paragraph was removed.

Recovery keeps known-season controls usable outside boundaries and never substitutes old-argument data. The slow action checks pending RTK reads and deduplicates rather than claiming cancel/restart. Existing75-second timeout remains. Callback rejection is handled locally, resets the synchronous pending lock and is unmount-safe. The shared test transport proves counters independently of the UI label.

Telemetry publishes no usable complete observation bounds: schedule time is not sample range, and resolution/aggregation/coverage are not bounds. Therefore no invented window/default/lap range or unsupported out-of-range guarantee. Strict calendar/time parsing preserves seconds/fractions/offsets; step1 (0.001 only for supplied subsecond precision), explicit guidance and <=120-second limits precede GET. Valid window with no samples stays source-no-data.

Density retains comparison/qualifying/contribution/heatmap/form and full context/readout. One summary precedes a full-width primary chart; native closed season-context disclosure mounts intelligence/timeline/spotlight/championship/latest/readout only when open. Metric definitions remain reachable. Confirmed dead overview strip UI/styles/test-only helpers were removed; rate assertions now test the live Form & insights model. Generic table ownership is in shared design-system/table.css imported by ui, not Race. New sizes are named Apex extensions; approved ribbon appearance/functionality is unchanged.
